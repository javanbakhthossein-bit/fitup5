# db-rescue/custom.db — نسخهٔ نجات دیتابیس (v141)

این فایل **نسخهٔ تمیز و راستی‌آزمایی‌شدهٔ** دیتابیس فیتاپ است:

- `PRAGMA integrity_check` → **ok**
- **۵۸۱ حرکت** در بانک حرکات (ExerciseLibrary)
- **۱۵۲۵ غذا** در بانک غذای ایرانی (FoodLibrary)
- **۵۴ جدول کامل** با آخرین اسکیمای v141 (شامل HeadCode، SiteSetting، ...)
- داده‌های پایه: مقالات seed، تنظیمات سایت، کاربران seed

## چه کسی آن را نصب می‌کند؟

**هیچ‌کس به‌صورت خودکار روی دیتابیس سالم!** در `deploy.sh` قدم «۱-الف — نگهبان دیتابیس»
این اسکریپت را اجرا می‌کند (`scripts/rescue-db.ts`):

- اگر `db/custom.db` سرور **سالم** باشد → ✋ هیچ کاری نمی‌کند (دیتای واقعی کاربران محفوظ می‌ماند)
- اگر **خراب** باشد (`integrity_check ≠ ok`) یا **جداول کلیدی را نداشته باشد**
  (مثل خروجی اسکریپت ترمیم ناقص) → بکاپ از فایل خراب در `db/corrupt-backup-<زمان>/`
  و نصب همین نسخهٔ تمیز جای آن

## نجات فوری بدون دیپلوی کامل

```bash
cd /var/www/fitup
unzip -o fitup-db-rescue-YYYY-MM-DD.zip -d /tmp/rescue && cp -r /tmp/rescue/* .
pm2 stop fitup
bun run scripts/rescue-db.ts --force
pm2 restart fitup
```

⚠️ این فایل داخل پوشهٔ `db-rescue/` سفر می‌کند (نه `db/`) تا `unzip -o` زیپ دیپلوی
هرگز به‌صورت خودکار روی دیتابیس زندهٔ سرور نمی‌نویسد.
