## ✨ چی‌عوض شده در v12.4 (فیکس خطای XML سایت‌مپ — EntityRef)

- **🗺 فیکس «error on line 322: EntityRef: expecting ';'» در سایت‌مپ:** ریشه = سریالایزر داخلی Next.js برای route متادیتای `app/sitemap.ts` کاراکتر «&» را escape نمی‌کند → URLهای دسته‌بندی مقالات («/?screen=articles&category=...») یک «&» خام وارد XML می‌کردند؛ گوگل پارسر XML روی خط ۳۲۲ (اولین URL دسته‌بندی) متوقف می‌شد و کل سایت‌مپ «قابل خواندن نبود» (دقیقاً همان خطای جدید سرچ کنسول بعد از رفع 404).
- **فیکس ریشه‌ای:** `/sitemap.xml` حالا یک route handler واقعی (`src/app/sitemap.xml/route.ts`) است که XML را با تابع مشترک `buildSitemapXml` (xmlEscape صریح «&» → «&amp;») می‌سازد — همان منبع `/api/sitemap`. فایل `app/sitemap.ts` حذف شد (دیگر هیچ مسیری به سریالایزر بدون‌escape تکیه ندارد). هدرهای Cache-Control و X-Sitemap-* هم خروجی می‌روند.
- **تست سندباکس:** ۱۳۹۶ URL، پارسر XML رسمی: VALID ✓، صفر «&» خام، «&amp;category=...» در خروجی نهایی.
- **بعد از دیپلوی:** در سرچ کنسول دوباره RESUBMIT بزنید؛ خطای «Sitemap could not be read — General HTTP error» باید بعد از پردازش پاک شود.
- 📱 تغییر native اندروید نداشت → APKها همان v1.4.0 / v1.1.0 (طبق OWN-APP-GUIDE: تغییرات وب نیاز به APK جدید ندارد).

## 🛡️ چی‌عوض شده در v10 — فیکس قطعی خطای لاگین (ستون `lastActiveAt`)

**مشکل:** بعد از دیپلوی v9، ورود با هر شماره‌ای خطا می‌داد:
`The column main.User.lastActiveAt does not exist in the current database`

**ریشه:** کد جدید فیلد تازه می‌خواند ولی `db:push` روی سرور اجرا نشده بود (و deploy.sh قدیمی خطایش را بی‌صدا پنهان می‌کرد: `|| echo "دیتابیس همگام است"`).

**سه فیکس ریشه‌ای در v10:**

1. **خودترمیمی دیتابیس (مهم‌ترین):** ۸ ثانیه بعد از هر بار روشن‌شدن سرور، اگر ستونی که کد انتظار دارد در دیتابیس نباشد، **خودش ساخته می‌شود** (route جدید `/api/cron/db-selfheal` + اجرا در boot با retry ۵ مرحله‌ای + چک هر ۶ ساعت). حتی اگر `db:push` فراموش شود یا شکست بخورد، لاگین هرگز به‌خاطر schema نمی‌شکند. حتی بدون `CRON_SECRET` هم کار می‌کند (اتصال boot محلی است).
2. **deploy.sh دیگر خطا را پنهان نمی‌کند:** اگر `db:push` شکست بخورد، پیام واقعی چاپ می‌شود و ادامه می‌دهد (خودترمیمی پشتیبان است).
3. **db:push دستی بدون توقف اپ هم ممکن است** — ولی اگر pm2 شما از دیتابیس داخل `.next/standalone/db/` استفاده می‌کند (آدرس نسبی)، فقط روی فایل منبع اثر نمی‌گذارد؛ خودترمیمی v10 دقیقاً داخل پروسه‌ی سرور اجرا می‌شود پس همان فایلی را که سرور واقعاً می‌خواند ترمیم می‌کند.

> **اگر همین حالا سرور شما خطای لاگین دارد:** سریع‌ترین راه دیپلوی v10 با چهار دستور بالا است — ۸ ثانیه بعد از بالا آمدن سرور، ستون خودکار ساخته می‌شود و لاگین درست می‌شود. راه دیگر: اجرای دستی `bun run db:push` روی سرور (اگر خطا داد، متن خطا را بفرستید).

## 📋 چی‌عوض شده در v9 (تمدید + نوتیف‌ها + سئو + اپ بازار + سرعتی)

### ۱. تجربه تمدید اشتراک — جدید و جذاب
- صفحه اختصاصی «تمدید اشتراک» (`renewal-overlay`): رینگ شمارش روزهای باقی‌مانده، آمار دوره («در این دوره چه ساختی؟» — تغییر وزن/تمرین‌ها/روزهای همراهی)، کد تخفیف ۱۵٪ اختصاصی با دکمه کپی، محاسبه قیمت نهایی، مزایا و مسیر ارتقا.
- برای **همه** پلن‌ها یکسان کار می‌کند — خریداری‌شده و ادمین‌فعال (هر دو از همان اشتراک User و کد تخفیف تمدید استفاده می‌کنند).
- ورودی‌ها: کارت «تمدید» داشبورد، بنر تب پلن‌ها، کلیک نوتیف‌های تمدید/انقضا، و لینک مستقیم `?renewal=1` (حتی اگر لاگین نباشید: اول ورود، بعد صفحه تمدید).
- API کد تخفیف حالا آمار دوره را هم برمی‌گرداند (تمرین‌های ثبت‌شده + وزن شروع/فعلی + شروع دوره).

### ۲. ریشه‌ای: نوتیف «چند روزی نیستی» برای کاربر فعال دیگر نمی‌آید
- **علت:** «آخرین فعالیت» فقط از ثبت وزن/چکاپ/چت/ساخت برنامه خوانده می‌شد — کاربری که هر روز اپ را باز می‌کرد ولی چیزی ثبت نمی‌کرد، «غایب» تلقی می‌شد.
- **فیکس:** فیلد جدید `User.lastActiveAt` (هر باز شدن اپ/سایت در `/api/auth/me` با throttle ۳۰ دقیقه + هر لاگین). جاروی رفتاری حالا فقط برای کسی که واقعاً ۷+ روز هیچ نسبتی با فیتاپ نداشته پیام می‌فرستد + سیگنال‌های مکمل (لاگ غذا، وضعیت روز تمرین و…).
- متن‌ها انسانی شدند: «{نام} دنبال‌ت بودیم 🧡»، «۳ روز تا پایان پلن استاندارد ⏳ اگه گل نزنی…»، «پلن پیشرفته تمام شد ⏸ پیشرفتت از بین نرفته…»، «هنوز می‌شه ادامه داد 🎁» — لینک همه به صفحه تمدید (`?renewal=1`).
- کاربران قدیمی بدون داده فعالیت، اولین اجرا seed می‌شوند (بدون اسپم).

### ۳. پیشنهاد پلن انتهای آنبوردینگ — ۸۰۰ هزار به بالا
- پلن اقتصادی (۳۵۰ هزار تومان) **دیگر هرگز** پیشنهاد خودکار نمی‌شود؛ پیشنهاد همیشه استاندارد/پیشرفته/حرفه‌ای است (مبتدی با هدف چربی‌سوزی/عضله‌سازی → پیشرفته).

### ۴. پروفایل سبک + مودال «پرونده ورزشی»

### ۵. سئو — ایندکس سریع و تمرکز رتبه

- **IndexNow فوری:** انتشار یا ویرایش مقاله لحظه‌ای به موتورهای جستجو اطلاع می‌دهد (faire-and-forget — قبلاً فقط کرون روزانه).
- sitemap.xml (۱۳۰۰+ URL) و robots.txt ممیزی شد — سالم؛ سرعت صفحه با lazy-loading زیر ساخت بهبود یافت (Core Web Vitals).
