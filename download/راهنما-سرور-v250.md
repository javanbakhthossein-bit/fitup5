## ۱️⃣ دستورات دیپلوی (سرِجا)

```bash
cd /var/www/fitup

# ۰) بکاپ فایل‌های حساس
sudo cp .env /root/fitup-env-backup-$(date +%F).txt
sudo cp Caddyfile /root/fitup-caddy-backup-$(date +%F)

# ۱) زیپ را سرِجا باز کن (زیپ بدون پوشهٔ ریشه است)
unzip -o /path/to/fitup-deploy-2026-11-01-v250.zip -d .

# ۲) نصب وابستگی‌ها + بیلد
bun install
bun run build

# ۳) ری‌استارت سایت
pm2 restart fitup
```

> ⚠️ **پیش از build، تست تایپ هم داخل بیلد اجرا می‌شود** — این نسخه `tsc` کامل را پاس می‌کند (روی سندباکس `bunx tsc --noEmit` = صفر خطا). اگر باز خطای تایپ دیدی، خروجی را کامل برایم بفرست.

> 💡 **دیتابیس دست نخورده می‌ماند** — زیپ شامل `db/` نیست و unzip هیچ‌وقت فایل موجود را حذف نمی‌کند. اسنپ‌شات فقط «بکاپ ایمنی» است، برای دیپلوی این نسخه لازم نیست.
