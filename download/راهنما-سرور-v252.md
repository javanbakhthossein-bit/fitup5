## ⚠️ مهم‌ترین نکتهٔ این نسخه — درگاه پرداخت دوم «زیبال» فعال می‌شود

این نسخه **درگاه پرداخت زیبال** را به‌عنوان درگاه دوم (بعد از زرین‌پال) اضافه می‌کند:

- ✅ **زرین‌پال بایت‌به‌بیت مثل قبل کار می‌کند** — صفر تغییر رفتاری؛ همهٔ مسیرها (وب/اپ اختصاصی/اینستاگرام) دست‌نخورده.
- ✅ **کافه‌بازار کاملاً دست‌نخورده** — سازوکار IAP خودش را دارد و به هیچ‌کدام از تغییرات وصل نیست (مارکرهای v245 سرجاست).
- 🆕 **زیبال**: سازوکار دو مرحله‌ایِ هم‌الگوی زرین‌پال (صفحهٔ میانی `/pay/{trackId}` → `gateway.zibal.ir/start/{trackId}` با Referer درست)، verify سروری، کال‌بک آداپتور اختصاصی، recover/کرون و استعلام چنددرگاهی.

### 🔑 گام الزامی — کلید زیبال در `.env` سرور

**قبل از ری‌استارت نهایی، این خط را به `.env` سرور اضافه کنید:**

```bash
ZIBAL_MERCHANT_ID=6addcadd45ce72c2cfba0ba6
```

- این همان کد مرچنت واقعی درگاه زیبال فیتاپ است (IP سرور قبلاً در پنل زیبال ثبت شده — خطای ۱۲۱/۱۱۵ یعنی IP ثبت نشده).
- اگر این کلید ست نشود: زیبال «پیکربندی‌نشده» تلقی می‌شود، انتخابگر درگاه دوم در مدال پرداخت **نشان داده نمی‌شود** و همه‌چیز دقیقاً مثل v251 فقط با زرین‌پال کار می‌کند (رفتار امن پیش‌فرض — هیچ‌چیز نمی‌شکند).
- `.env` داخل ZIP نیست (طبق همیشه) — کلیدهای فعلی سرور دست نمی‌خورند.

## ۲) دیپلوی (۴ دستور)

```bash
cd /var/www/fitup && unzip -o .../fitup-deploy-2026-11-02-v252.zip -d .
bunx prisma db push          # ← الزامی (فقط همین یک ستون additive)
echo 'ZIBAL_MERCHANT_ID=6addcadd45ce72c2cfba0ba6' >> .env
bun run build
pm2 restart fitup
```

> **تغییر دیتابیس در v252:** فقط یک ستون — `Payment.gateway TEXT NULL` (زرین‌پال/زیبال؛ ردیف‌های قدیمی NULL می‌مانند و همیشه زرین‌پال تفسیر می‌شوند). هیچ داده‌ای تغییر نمی‌کند، هیچ ردیفی حذف نمی‌شود.

## ۳) چک‌لیست بعد از دیپلوی (۸ قدم)

1. `curl -s -o /dev/null -w "%{http_code}" https://fittup.ir/` → **200**
2. **مدال پرداخت وب**: انتخاب یک پلن → بخش «درگاه پرداخت» با دو کارت دیده شود: «زرین‌پال (پیشنهادی)» و «زیبال»
3. **پرداخت زرین‌پال E2E** (مطابق همیشه) — موفق
4. **پرداخت زیبال E2E**: انتخاب زیبال → «رفتن به درگاه پرداخت» → باز شدن درگاه زیبال (پیام «درگاه زیبال» در صفحهٔ میانی) → پرداخت آزمایشی کوچک → بازگشت و فعال‌سازی پلن
5. **اپ اختصاصی اندروید**: پرداخت زرین‌پال از داخل اپ دقیقاً مثل قبل (پل native) — موفق؛ در اپ هم انتخابگر دو درگاه دیده می‌شود (زیبال از پل وبِ تاب‌آور می‌رود — بازگشت به اپ با دیپ‌لینک مثل زرین‌پال)
6. **اپ کافه‌بازار**: خرید IAP بازار کاملاً مثل قبل (انتخابگر درگاه در اپ بازار هیچ‌گاه نشان داده نمی‌شود)
7. **پنل مدیر → مالی و تراکنش‌ها**: فیلتر «درگاه» (همه درگاه‌ها/زرین‌پال/زیبال) کار کند؛ هر تراکنش درگاهی بج رنگی درگاه داشته باشد (کهربایی=زرین‌پال، سبز=زیبال)؛ دکمهٔ استعلام برای هر دو درگاه جواب درست بدهد
8. `curl -s https://fittup.ir/sitemap.xml | grep -c "<url>"` → ≥ ۲۲۹۶ (بدون کاهش)
