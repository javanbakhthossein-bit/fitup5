## ⚡ دیپلوی سایت — استخراج سرِجا در همان پوشهٔ فعلی سایت

> 🔴 **نکتهٔ حیاتی:** این زیپ **پوشهٔ ریشه ندارد** — زیپ را باید **در همان `/var/www/fitup`** استخراج کنید (نه پوشهٔ جدید). اگر جای دیگری باز کنید، pm2 همان پوشهٔ قبلی را سرو می‌کند و سایت آپدیت نمی‌شود.

```bash
cd /var/www/fitup
cp .env .env.bak-v242                      # احتیاط
cp Caddyfile Caddyfile.bak-v243 2>/dev/null
unzip -o fitup-deploy-2026-10-18-v243.zip -d .
bun install && npx prisma generate && bun run build
pm2 restart fitup
```

- ⚠️ **`npx prisma db push` لازم نیست** — صفر تغییر اسکیما (فقط دو خط index خرابِ schema فیکس شد که روی دیتابیس موجود اثری ندارد).
- ⚠️ **ویدیوها** در زیپ نیستند — پوشهٔ `public/videos` سرور دست‌نخورده می‌ماند.
- 📁 اگر زیپ را جای دیگری آپلود کرده‌اید: `find / -name "fitup-deploy-2026-10-18-v243.zip" 2>/dev/null`

## 🤖 سرویس اتوپست کانال بله — آپدیت به v243 (اجباری)

**چه چیز جدیدی دارد:**
1. **۴ پست در روز:** ۰۹:۰۰ راهنمای علمی + عکس / ۱۳:۰۰ کوئیز / **۱۷:۰۰ مقالهٔ روز (عکسِ کاور مقاله از سایت + تیزر خیلی خلاصه + لینک خواندن)** / ۲۱:۰۰ انگیزشی
2. **فیکس پست تکراری:** اگر سرویس دیر روشن شود، اسلاتِ گذشتۀ دیگر «جبران» نمی‌شود (ریشهٔ پست تکراری ۱۰:۱۵ دیروز). گرِیس فقط ۱۰ دقیقه است.
3. مقاله‌ها مستقیم از دیتابیس سایت با کاور و خلاصهٔ واقعی — چرخش ۶۷ روزه، هیچ مقاله‌ای دوباره نمی‌افتد.

```bash
# اول پروسهٔ فعلی را کامل پاک کنید:
pm2 delete fitup-bale-autopost

cd /var/www/fitup/mini-services/bale-autopost
bun install
pm2 start "bun index.ts" --name fitup-bale-autopost && pm2 save
```

> ⚠️ `pm2 start` همیشه **پوشهٔ فعلی ترمینال** را ثبت می‌کند — حتماً اول `cd` کنید بعد start.
> ⚠️ پوشه‌های `state/` و `outbox/` و `logs/` دیگر داخل زیپ نیستند — استخراج زیپ وضعیت سرویس شما را خراب نمی‌کند.

**چک سلامت:**
```bash
curl http://localhost:3050/status
```
- `"version": "v243-0"` و `"dryRun": false` باشد
- `times` باید ۴ اسلات داشته باشد: `morning/noon/article/evening`
- `textVia = deepseek-v4.1-flash` و `avalaiModel = gemini-3.1-flash-lite-image`

**تست دستی یک پست (بدون منتظرماندن برای ساعت):**
```bash
curl -X POST "http://localhost:3050/run?slot=article&key=fitup-admin"
```
(`slot` می‌تواند `morning` / `noon` / `article` / `evening` باشد — پست واقعاً به کانال می‌رود)
