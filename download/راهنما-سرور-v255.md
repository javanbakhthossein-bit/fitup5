## ۱) محتوای این آپدیت (خلاصهٔ مالک)

ممیزی ریزبه‌ریز **۹۳ برنامهٔ فعال ماه گذشته** انجام شد و ۷ باگ (B1–B7) ریشه‌ای فیکس شد:

| باگ | شرح | فیکس |
|---|---|---|
| B1 | پوشش ناقص ۶ گروه عضلانی (۱۳ برنامه) | کلاسیفایر «مرکز بدن» + اجرای واقعی ترمیم پوشش (L2.10) |
| B2 | کاربر خانگی حرکت باشگاهی می‌گرفت (۲ برنامه) | تعویض قطعی هم‌عضله از بانک ویدیودار (L2.8) |
| B3 | چربی‌سوزی بدون هیچ کاردیو (۱۰ برنامه) | تزریق قطعی ۲ کاردیوی ایمن (L2.9) |
| B4 | رژیم بدون استک مکمل در پلن استاندارد+ (۵۶ برنامه) | خالی‌بودن = critical → بازسازی هوشمند شخصی‌سازی‌شده |
| B5 | ۸ ایراد جریان تمدید (گارد برنامهٔ تازه، چرخهٔ دوبله، انکر بازیابی، کسر اعتبار روی دانگرید، تمدیدِ معلقِ در-انتظار-عکس، مدال الزامی، هدفِ غیرقابل‌ویرایش، یادآوری عکس بدن) | فیکس کامل + E2E پاس |
| B6 | استراحت صفر/نامشخص بین ست‌ها (۲۹ برنامه) | استاندارد علمی NSCA/Schoenfeld + ترمیم قطعی |
| B7 | برنامهٔ فال‌بک موتور محلی ضعیف | پروگرسیون موجی ۶هفته‌ای + حساسیت‌ها + تعداد وعده |

به‌علاوه فیکس «پارالل-گیت» (دیپس پارالل کاذب گروه پا حساب می‌شد).

## ۲) دیپلوی (مثل همیشه)

```bash
cd /var/www/fitup
# بکاپ DB قبل از هر کاری
cp db/custom.db db/custom.db.pre-v255-$(date +%H%M)
# باز کردن زیپ روی سورس موجود (رسانه‌ها دست نمی‌خورند — در زیپ نیستند)
unzip -o fitup-deploy-2026-11-04-v255.zip -d /var/www/fitup
bun install
bun run build  # یا ری‌استارت سرویس طبق روال قبلی
pm2 restart fitup  # یا سرویس معادل
```

> ⚠️ زیپ جدید **فقط سورس کد** است — فایل‌های رسانهٔ `public/` و APKها و DB روی سرور سر جای خودشان هستند و پاک نمی‌شوند (unzip فقط فایل‌های داخل زیپ را بازنویسی می‌کند).

## ۳) اجرای بازتولید کاربران باگ‌دار (الزامی — بعد از دیپلوی)

اسکریپت `scripts/regen-affected-plans-v255.ts` برنامه‌های باگ‌دارِ ۴۵ روز اخیر را پیدا و ترمیم می‌کند:
- **مسیر قطعی (بدون AI):** ترکیب‌های پوشش/تجهیزات/کاردیو/استراحت → درجا ترمیم می‌شوند (ثانیه‌ای، بدون هزینه).
- **مسیر هوشمند (با AI سرور):** استک مکمل خالی (B4) و برنامه‌های فال‌بک (B7) → بازتولید کامل با هوش مصنوعی.

```bash
cd /var/www/fitup

# ① خشک — فقط نشان می‌دهد چه کسانی باگ دارند (هیچ تغییری نمی‌دهد)
DATABASE_URL=file:./db/custom.db bun scripts/regen-affected-plans-v255.ts

# ② اجرا — ترمیم قطعی درجا + شروع بازتولید هوشمند (سقف ۴۰ نفر در هر اجرا)
DATABASE_URL=file:./db/custom.db bun scripts/regen-affected-plans-v255.ts --execute

# ③ اگر تعداد بیشتری بود، دوباره اجرا کنید (idempotent است — ترمیم‌شده‌ها دیگر فلگ نمی‌شوند)
DATABASE_URL=file:./db/custom.db bun scripts/regen-affected-plans-v255.ts --execute --limit 40
```

**نکته‌ها:**
- کاربرانی که برنامه‌شان کمتر از ۲۴ ساعت است و کاربرانِ در-انتظار-عکس-بدن skip می‌شوند — ۲۴ ساعت بعد دوباره اسکریپت را اجرا کنید (فقط خشک بزنید ببینید کسی مانده یا نه).
- کاربران b4/b7 با AI بازتولید می‌شوند → گیت کیفیت v255 (تجهیزات/کاردیو/پوشش/استراحت/مکمل) خودش روی تولید جدید اجرا می‌شود؛ **باگ دیگر تکرار نمی‌شود.**
- راستی‌آزمایی اختیاری لایه‌های گیت روی سرور:
  ```bash
  DATABASE_URL=file:./db/custom.db bun scripts/test-gate-layers-v255.ts
  DATABASE_URL=file:./db/custom.db bun scripts/test-rest-fix-v255.ts
  ```
