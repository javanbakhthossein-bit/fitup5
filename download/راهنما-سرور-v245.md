|---|------|-------|
| ۱ | **اسنیپت خام Clarity ادمین دیگر رندر نمی‌شود** | ممیزی HTML پروود نشان داد اسنیپت ادمین با `insertBefore(t,y)` که یک `<script>` را «وسط head» درج می‌کرد هنوز زنده بود (درست همان وسط walk هیدریشن React روی موبایل‌های کند). حالا HeadCodeInjector این قطعهٔ خاص را فیلتر می‌کند — Clarity همچنان با لودر گارددار خودِ سایت (appendChild انتهایی، بعد از load) بار می‌شود. **هیچ چیزی از تحلیل رفتار کم نمی‌شود.** |

| ۳ | **تاریخ زندهٔ داشبورد (LiveDate)** | مقدار اولیه با Intl fa-IR سمت سرور می‌توانست روی WebViewهای ICU-ناقص فرق کند (کلاس `args[]=text`) — حالا اولین رندر دو طرف یکسان است |

## ۱️⃣ دستورات دیپلوی (سرِجا — ساده‌تر از v244 چون کد بله عوض نشده)

```bash
cd /var/www/fitup

# ۰) بکاپ فایل‌های حساس
sudo cp .env /root/fitup-env-backup-$(date +%F).txt
sudo cp Caddyfile /root/fitup-caddy-backup-$(date +%F)

# ۱) زیپ را سرِجا باز کن (زیپ بدون پوشهٔ ریشه است)
unzip -o /path/to/fitup-deploy-2026-10-18-v245.zip -d .

# ۲) نصب وابستگی‌ها + بیلد
bun install
bun run build

# ۳) ری‌استارت سایت
pm2 restart fitup
```
