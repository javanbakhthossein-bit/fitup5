## 🚀 دیپلوی — فقط ۲ گام (مثل همیشه)

### گام ۱ — آپلود و ری‌استارت
فایل زیپ را در پوشهٔ سایت باز کنید و بعد دستورات زیر (همان بلوک همیشگی):

```bash
cd /var/www/fitup
unzip -o /path/to/fitup-deploy-2026-10-09-v229.zip -d /var/www/fitup
cd /var/www/fitup
bun install
bunx prisma generate
bun run build
pm2 restart fitup
```

### گام ۲ — چک ۳۰ ثانیه‌ای (بدون دانش فنی)
1. سایت را باز کنید → باید مثل قبل بالا بیاید.
2. با یک حسابِ بدون پلن وارد شوید → صفحهٔ تحلیل (یا مسیر آنبوردینگ تا تحلیل) → **یک نوار نارنجیِ کم‌ارتفاع پایین صفحه می‌بینید** («پلن پیشرفته — ۱٬۰۸۰٬۰۰۰ تومان / خرید با تخفیف») → درست است.
3. تا آخرِ همان صفحه اسکرول کنید → دکمهٔ «رفتن به داشبورد» باید **کامل و بدون پنهان‌شدن** دیده شود → درست است.
4. روی بنر زرد «ده درصد تخفیف» بزنید → باید نرم به کارت پلن پیشنهادی اسکرول شود → درست است.
5. همین ۴ مورد کافی است. بعد از چند روز، پنل ادمین → قیف فروش، دو ردیف جدید می‌بینید:
   «دیدن نتیجهٔ تحلیل (آماده شد)» و «تخفیف صفحهٔ تحلیل واقعاً مصرف شد» + ستون دستگاه «پرداخت موفق» دیگر «نامشخص» ندارد.

## 🧾 داخل این نسخه چیست؟ (خلاصهٔ غیرفنی)

| بخش | تغییر | چرا |
|---|---|---|
| **اندازه‌گیری فروش** | خرید موفق حالا دستگاه/منبع درست ثبت می‌کند + ۴ سنجهٔ جدید + سقف رویداد روزانه + سشن واقعی | تا تصمیم‌های فروش روی اعداد درست گرفته شود (قبلاً ۱۱ خریدِ موفق همه «نامشخص» بودند) |
| **صفحهٔ تحلیل** | نوار خرید چسبان + بنر تخفیف کلیک‌پذیر + تخفیف در مدال از هر مسیری دیده می‌شود | بیشترین ریزشِ واقعی قبل از پرداخت اینجاست — CTA همیشه در دید |
| **بازار قدیمی** | پیام «لطفاً برنامه را بروز کنید تا تخفیف شما اعمال شود» + توقف خریدِ قیمت کامل + حفظ تخفیف بعد از بروزرسانی | دیرکتیو مستقیم شما — دیگر کسی با قیمت کامل ناغافل پرداخت نمی‌کند |
| **ممیزی پرداخت** | ۵ فیکس (ثبت انصراف/شکست درگاه، اعتبار ارتقا، خودترمیمی توکن، …) | همهٔ ریزش‌های درگاه از این به بعد در داشبورد دیده می‌شوند |
| **گوشی ضعیف** | سبک‌سازی بی‌صدا (گرم‌کردن چانک در اپ، پالس ۸ ثانیه‌ای در اپ، ۶ اشتراک سنگین حذف شد) | رفع «هنگ کردن» — بدون هیچ تغییر ظاهری |
