**چرا VAPID؟** در ممیزی مشخص شد کلید VAPID فقط در `.env.example` بود و روی سرور ست نشده — مسیر `/api/push/vapid-key` خطای ۵۰۰ می‌داد و نوتیفیکیشن وب‌پوش از کار افتاده بود. با این مقادیر فیکس شد. اگر قبلاً روی سرور کلید دیگری برای push ست شده، **همان را نگه دارید** (سازگاری سابسکریپشن‌های فعلی) و فقط اگر خالی است این مقادیر را بگذارید.

**دفاع جدید زیبال:** اگر روزی مرچنت تستی عمومی (`zibal`) یا مرچنت خالی/TEST در env سرور مانده باشد، سیستم به‌جای «پرداخت شبیه‌سازی‌شدهٔ موفق»، زیبال را **پیکربندی‌نشده** حساب می‌کند، درگاه دوم از مدال حذف می‌شود و همه‌چیز فقط با زرین‌پال کار می‌کند — **هیچ فعال‌سازی مجانی ممکن نیست**.

## ۱) بکاپ (قبل از هر کاری)

```bash
sudo cp /var/www/fitup/db/custom.db /root/fitup-db-backup-before-v252-1-$(date +%F).db
```

## ۲) دیپلوی (۴ دستور)

```bash
cd /var/www/fitup && unzip -o .../fitup-deploy-2026-11-02-v252-1.zip -d .
bun install --frozen-lockfile
bun run db:push
sudo systemctl restart fitup   # یا روش ری‌استارت همیشگی شما
```

> `db:push` در ممیزی با `migrate diff` تأیید شد: **No difference detected** — یعنی دیتابیس فعلی با همین اسکیما سینک است و push فقط تأیید/بی‌اثر است. `db-schema-ddl.ts` (پشتیبان self-heal) هم بازتولید شد و الان ۶۱ جدول را پوشش می‌دهد (۷ جدول جاافتاده + ستون‌های جدید مثل `Payment.gateway` اضافه شدند).

## ۳) راستی‌آزمایی پس از دیپلوی (۵ دقیقه — حتماً)

```bash
# ۱) سلامت کلی
curl -s -o /dev/null -w "%{http_code}\n" https://fittup.ir/                 # 200
curl -s https://fittup.ir/api/payment/checkout | head -c 300                # gateways باید شامل zibal باشد
curl -s -o /dev/null -w "%{http_code}\n" https://fittup.ir/api/push/vapid-key  # 200 (با کلید VAPID)

# ۲) سئوی صفحهٔ tdee — باید ۵ اسکیما در HTML خام باشد
curl -s https://fittup.ir/tdee | grep -c 'application/ld+json'              # ≥ 5

# ۳) لاگ — نباید خطای [zibal] مرچنت تستی ببینید
journalctl -u fitup -n 50 | grep -i zibal
```

**تست پرداخت واقعی (زیبال):** یک شارژ کیف‌پول کم‌مبلغ (مثلاً ۱۰ هزار تومان) از پنل کاربری با درگاه زیبال بزنید → پرداخت کامل → در پنل ادمین، تب مالی، ردیف باید **بج «زیبال»** و وضعیت success داشته باشد. سپس دکمهٔ بازیابی/رفرش رسید را بزنید — نباید چیزی دوباره شارژ شود (idempotency). مبلغ باقیمانده را می‌توانید از پیشخان زیبال استرداد کنید.

**تست زرین‌پال:** همان تست با درگاه زرین‌پال (یکی کافی است) — رفتار باید بایت‌به‌بیت مثل v251 باشد.
