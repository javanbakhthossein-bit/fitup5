## ۱️⃣ چرخهٔ زندهٔ مقاله‌ها — چطور کار می‌کند؟

**تا v243:** سرویس بله لیست مقاله‌ها را از فایل ثابت `articles.json` می‌خواند — مقالهٔ جدید فقط با بازتولید دستی وارد چرخه می‌شد.

**از v244:**
- سرویس بله (اسلات ۱۷:۰۰) لیست را **زنده** از `https://fittup.ir/api/bale/articles` می‌خواند
- آن endpoint **فقط مقاله‌های `published`** را برمی‌گرداند → مقاله‌های «در صف انتشار» (draft با scheduledAt) **هرگز** به کانال نمی‌روند
- مرتب‌سازی: **جدیدترینِ منتشرشده اول** → مقاله‌ای که امروز منتشر کردید، در همان اسلات ۱۷:۰۰ امروز وارد چرخه می‌شود
- امنیت خطا: اگر سایت در دسترس نبود، سرویس با «کش دیروز» یا فایل ثابت articles.json کار می‌کند (هیچ‌وقت بی‌لیست نمی‌ماند)
- وضعیت را این‌طوری ببینید: `curl http://127.0.0.1:3050/status` → بخش `articles` (تعداد / منبع / مقالهٔ بعدی)

⚠️ **نکته:** endpoint `/api/bale/articles` عمومی است ولی فقط متادیتای مقاله‌های منتشرشده را می‌دهد (همان چیزهایی که خود سایت عمومی نشان می‌دهد) — عنوان/خلاصه/کاور/لینک. هیچ محتوا یا چیز خصوصی‌ای ندارد.

## ۲️⃣ دستورات دیپلوی (سرِجا — همان الگوی v243)

```bash
cd /var/www/fitup

# ۰) بکاپ فایل‌های حساس
sudo cp .env /root/fitup-env-backup-$(date +%F).txt
sudo cp Caddyfile /root/fitup-caddy-backup-$(date +%F)

# ۱) زیپ را پیدا و سرِجا باز کن (زیپ بدون پوشهٔ ریشه است)
find / -name "fitup-deploy-2026-10-18-v244.zip" 2>/dev/null
unzip -o /path/to/fitup-deploy-2026-10-18-v244.zip -d .

# ۲) نصب وابستگی‌ها + بیلد
bun install
bun run build

# ۳) ری‌استارت سایت
pm2 restart fitup   # یا: pm2 delete fitup && pm2 start bun --name fitup -- run start

# ۴) سرویس بله — تعویض کد (پوشه را عوض کن وگرنه pm2 مسیر ترمینال را ثبت می‌کند!)
pm2 delete fitup-bale-autopost
cd /var/www/fitup/mini-services/bale-autopost
bun install
pm2 start bun --name fitup-bale-autopost -- index.ts
pm2 save

# ۵) وریفای
curl -s http://127.0.0.1:3050/status | head -c 400
# باید ببینی: "version":"v244-0" و بخش "articles":{"count":67,...,"source":"site"}
```

**وریفای نهایی سایت:**
```bash
curl -s "https://fittup.ir/api/bale/articles" | head -c 300
# باید count:67 ببینی (فقط مقاله‌های منتشرشده)
curl -s -o /dev/null -w "%{http_code}\n" https://fittup.ir/api/cron/cleanup-media
# باید 401 ببینی (بدون راز → دسترسی ممنوع — گارد مشترک جدید)
```
