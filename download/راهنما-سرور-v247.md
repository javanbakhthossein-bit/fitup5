## ۱️⃣ دستورات دیپلوی (سرِجا)

```bash
cd /var/www/fitup

# ۰) بکاپ فایل‌های حساس
sudo cp .env /root/fitup-env-backup-$(date +%F).txt
sudo cp Caddyfile /root/fitup-caddy-backup-$(date +%F)

# ۱) زیپ را سرِجا باز کن (زیپ بدون پوشهٔ ریشه است)
unzip -o /path/to/fitup-deploy-2026-10-31-v247.zip -d .

# ۲) نصب وابستگی‌ها + بیلد
bun install
bun run build

# ۳) ری‌استارت سایت
pm2 restart fitup
```

⚠️ **سرویس بله (fitup-bale-autopost):** کدش در v247 عوض نشده و کانفیگ داخل زیپ دقیقاً همان مقدار فعلی سرور است (dryRun=false + همان توکن) → **نیازی به ری‌استارت نیست.**
```bash
curl -s http://127.0.0.1:3050/status | head -c 200
```
