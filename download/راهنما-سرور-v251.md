## ۱) بکاپ (قبل از هر کاری)

```bash
sudo cp /var/www/fitup/db/custom.db /root/fitup-db-backup-before-v251-$(date +%F).db
```

## ۲) دیپلوی (۴ دستور)

```bash
cd /var/www/fitup && unzip -o .../fitup-deploy-2026-11-02-v251.zip -d .
bunx prisma db push          # ← جدید در v251 — الزامی (فقط ۲ ستون additive)
bun run build
pm2 restart fitup
```

> **اگر بیلد شکست:** سایت را از بیلد قبلی بالا بیاورید (مثل روال همیشگی — standalone بکاپ hardlink) و خروجی خطا را بفرستید. بیلد این نسخه در سندباکس معادلش (`tsc --noEmit`) صفر خطا بوده است.

## ۳) چک‌لیست بعد از دیپلوی (۷ قدم)

1. `curl -s -o /dev/null -w "%{http_code}" https://fittup.ir/` → **200**
2. `curl -s -o /dev/null -w "%{http_code}" https://fittup.ir/article/ناموجود-تستی-xyz` → **404** (قبلاً 200/noindex بود — فیکس soft-404)
3. `curl -s https://fittup.ir/sitemap.xml | grep -c "<url>"` → **۲۲۹۶** (شامل /bmi و /1rm و /macro و ۳۲ صفحهٔ /free-programs/<id> و ۲ صفحهٔ /author/)
4. `curl -s https://fittup.ir/bmi` و `/1rm` و `/macro` و `/free-programs/muscle-gain-male-3` و `/author/hossein-javan` → همه **200**
5. صفحهٔ اصلی: در سکشن قیمت، عبارت «برنامهٔ اختصاصی فروخته و فعال شده» با عدد واقعی دیده شود؛ CTA دوم هیرو «دیدن پلن‌ها و قیمت‌ها» اسکرول به #pricing کند
6. **پرداخت E2E**: یک خرید آزمایشی واقعی در سایت (زرین‌پال) + در اپ بازار — مطابق همیشه؛ فایل‌های پرداخت در این نسخه صفر تغییر دارند (diff تأییدشده)
7. پنل مدیر → تب داشبورد: کارت‌های جدید «سلامت فروش (۴۵ روز اخیر)» — MRR، نرخ تمدید، نرخ درگاه‌ها، کوهورت و «اثر مالی کمپین‌ها»؛ اگر `ADMIN_PASSWORD` در env ست نباشد بنر کهربایی هشدار 2FA بالای KPIها دیده می‌شود
