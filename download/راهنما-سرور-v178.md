## گام ۱ — دیپلوی زیپ (مثل همیشه)

1. از پنل، زیپ `fitup-deploy-2026-10-01-v178.zip` را روی سرور آپلود و در پوشهٔ سایت unzip کنید
   (جایگزین فایل‌ها — پوشهٔ `db/` و `uploads/` سرور دست‌نخورده می‌مانند).
2. اگر `npm ci`/`bun install` لازم شد اجرا کنید (وابستگی جدیدی اضافه نشده ولی بی‌ضرر است).
3. `npx prisma db push` را اجرا کنید (دو فیلد جدید `signupSource`/`signupSourceDetail` روی جدول
   کاربران + جدول جدید `NotificationCampaign` ساخته می‌شود).
   ⚠️ اگر این گام را فراموش کنید، نگران نباشید: خودترمیمی دیتابیسِ سایت (db-selfheal) ستون‌های
   گم‌شده را ۸ ثانیه بعد از بوت خودش اضافه می‌کند — ولی اجرای دستی تمیزتر است.
4. سرویس سایت را ری‌استارت کنید (pm2 restart یا سرویس خودتان).

## گام ۲ — اجرای اسکریپت محتوا (مهم — ادغام دسته «تمرین» + منبع کاربران قدیمی)

روی سرور، داخل پوشهٔ اصلی سایت:

```bash
# اول گزارش بدون تغییر (اختیاری ولی توصیه‌شده):
node scripts/prod-sync-content-v178.mjs --dry-run

# بعد اعمال واقعی (خودش قبل از هر تغییر بکاپ کامل در db/backups می‌گیرد):
node scripts/prod-sync-content-v178.mjs
```

این اسکریپت:
- مقالهٔ دستهٔ `training` (همان «تمرین» تک‌مقاله‌ای) را به دستهٔ «تمرین» اصلی منتقل می‌کند و
  دسته‌های انگلیسی قدیمی (`supplement` و…) را هم ادغام می‌کند — بعد از آن فقط ۶ دستهٔ فارسی
  واحد در مجله می‌ماند.
- برای کاربران قدیمی، «منبع ثبت‌نام» را از سیگنال‌های موجود backfill می‌کند
  (اپ کافه‌بازار → کافه‌بازار، اپ اختصاصی → اپ اختصاصی، اینستاگرام → اینستاگرام).
- **ویدیوهای اختصاصی شما (بانک حرکات) را هیچ تضمینی تغییر نمی‌دهد** — این اسکریپت اصلاً
  به جدول حرکات دست نمی‌زند. (اسکریپت حرکاتِ v177 هم همین تضمین را دارد:
  `scripts/prod-sync-exercises-v177.mjs` — اگر هنوز روی سرور اجرا نشده، طبق فایل
  `scripts/exercise-sync-README-FA.txt` اجرا کنید؛ ویدیوی اختصاصیِ هر حرکت فقط اگر
  خالی باشد پر می‌شود، هرگز جایگزین نمی‌شود.)
- Idempotent است — چند بار اجرایش بی‌ضرر است.

## گام ۳ — (اختیاری) crontab برای دقت بیشتر نوتیف زمان‌بندی‌شده

نوتیف‌های زمان‌بندی‌شده به‌صورت پیش‌فرض **داخل خود سایت** (هر ۶۰ ثانیه، بدون کرون خارجی)
ارسال می‌شوند. اگر می‌خواهید دقتش دقیقاً «همان ثانیه» باشد، این خط را به crontab اضافه کنید:

```
* * * * * curl -s "http://localhost:3000/api/cron/dispatch-notifications?secret=$CRON_SECRET" > /dev/null
```

## گام ۴ — امضای لینک اینستاگرام (برای آمار «اینستاگرام» از این به بعد)

برای اینکه ثبت‌نام‌های اینستاگرام دقیق شمرده شوند، لینک بایو اینستاگرام را با پارامتر utm بدهید:

```
https://fittup.ir/?utm_source=instagram
```

(کاربران گوگل خودکار از روی referrer تشخیص داده می‌شوند؛ کاربران اپ کافه‌بازار و اپ اختصاصی
هم از روی خودِ اپ — نیازی به کاری ندارد.)

## ✅ تضمین ویدیوهای اختصاصی (سؤال شما)

بله — تضمین می‌دهم و دلیلش کد است، نه قول:

1. اسکریپت `prod-sync-exercises-v177.mjs` (حرکات) ویدیوی حرکت را **فقط وقتی می‌گذارد که
   خالی باشد**؛ اگر ویدیوی اختصاصی آپلودی داشته باشد، دست نمی‌زند. فیلد `videoUrl` آپلودیِ
   شما و فلگ `isActive` هرگز در مسیر update هیچ اسکریپتی نیست.
2. اسکریپت `prod-sync-content-v178.mjs` (این نسخه) اصلاً به جدول حرکات دست نمی‌زند.
3. هیچ کدی از پنل/سرور ویدیوی آپلودی شما را حذف نمی‌کند؛ ویدیوها فقط با حذف دستی خودِ
   حرکت از پنل حذف می‌شوند.

اگر خواستید قبل از اجرا خیالتان صددرصد راحت باشد: `--dry-run` را اجرا کنید — فقط گزارش
چاپ می‌کند و هیچ تغییری نمی‌دهد.
