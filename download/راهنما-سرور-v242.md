```bash
# اگر قبلاً یک بار اشتباهی pm2 start زده‌اید و وضعیت stopped است، اول پاکش کنید:

cd /var/www/fitup/mini-services/bale-autopost
bun install
pm2 start "bun index.ts" --name fitup-bale-autopost && pm2 save
```

- ساعت‌های پخش یا متن‌ها قابل تغییرند: `config.json` (ساعت‌ها) و `index.ts` (پرامپت‌ها) → بعدش `pm2 restart fitup-bale-autopost`.

## ✅ جدید در پنل ادمین — تگ «بله»

هر کسی که با لینک‌های کانال بله (utm_source=bale) ثبت‌نام کند:

1. **کاربران** → زیر نام کاربرش بج کهربایی «بله» می‌بینید (هم‌جای اینستاگرام/گوگل/کافه‌بازار).
2. **مالی و تراکنش‌ها** → همان بج کنار نام خریدار.
3. **داشبورد → «منبع کاربران و فروش»** → ردیف «بله» خودش اضافه می‌شود (ثبت‌نام، خرید، نرخ تبدیل).

تا اولین ثبت‌نام از بله، ردیف بله خالی است — طبیعی است.
